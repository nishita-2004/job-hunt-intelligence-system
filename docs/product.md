# Job Hunt Intelligence System

## Vision

Build a career intelligence product that helps job seekers
make better career decisions using data.

## Initial Problem

Job seekers apply to many jobs but often don't know:

- which roles perform best
- which sources produce interviews
- which companies respond
- where their application funnel leaks
- which strategy they should prioritize

## Initial Product

A job application intelligence system that turns
application history into actionable insights.

## First Core Question

Where is my job search breaking down?

## Long-Term Direction

Career intelligence and decision support.
